Set 模型

  • 10,573,442 参数；d_model=384。
  • 两层 ISAB，128 inducing points，8 heads。
  • Stage A/B 各 1,000 updates，batch 384。
  • 无 gene-specific embedding，可跨 3,000 → 759 genes strict load。

两种速度监督

  • Phase：batch 内按基因共享的 u~s 线性趋势 residual。
  • Teacher：蒸馏旧 denoising-first 的 spliced velocity 方向。
  • 两者均优化 cosine，并以极小 collapse penalty 防止速度幅度退化。

证据支持

  1. 跨数据集预训练能够学习可迁移的 velocity 方向。
  2. 纯 denoising 比当前弱 ODE 预训练更有成本效益。
  3. state/velocity 分阶段与冻结机制值得继续推进。
  4. 选模必须联合 Raw/Graph CBDir、confidence、速度幅度和 ICCoh。

证据尚不支持

  1. 参数增大本身会改善 RNA velocity。
  2. 高 ICCoh 等价于生物方向正确。
  3. 当前 Set 结构优于同参数 standard attention。
  4. 已达到跨组织、跨物种的通用 foundation model。
Decision log

当前结论与建议的实验顺序

  1. 先完成正在运行的对照。补齐 Set phase seed 2–4 与 standard-attention seed 0，再更新结构结论。
  2. 保留 denoising 与 v2 teacher/phase 三类 checkpoint。前者是旧路线最强 zero-shot，后两者分别代表均衡性与 raw direction。
  3. 测试低破坏适配。依次比较 zero-shot、head-only、gradual unfreeze、full model；学习率降低，并对图损失归一化与 ramp。
  4. 以多种子 Graph CBDir 为主要决策量。同时报告 velocity magnitude/variance、confidence、ICCoh 与失败率，防止近常量平滑解。
  5. 再做动力学重构。将 cell×gene 独立闭式参数改为 gene-level 或 hierarchical shared kinetics；先做 data/compute-matched 消融。
  6. 最后扩大泛化范围。严格 study/donor split、跨组织外部集和 ortholog-aware 人鼠映射应先于更大模型或全 36,601-gene dense 架构。
推荐的近期判定门槛：如果 Set/standard 对照在至少 3 个 seed 上仍能稳定达到 Graph CBDir ≥ 0.70，并且适配后不低于 zero-shot，则再进入更大数据预算与跨组织验证；否则优先修复目标函数和适配策略，而非扩容。
